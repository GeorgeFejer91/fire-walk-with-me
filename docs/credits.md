# Credits and asset provenance

- Native GTK/XFWM theme derives from **Redmond97 SE**, by Sliver_X: [upstream](https://codeberg.org/Sliver_X/Redmond97-SE). GPL-3.0 license and source notes are in `licenses/Redmond97-SE.txt`. This project changes the palette, patterns, panel integration and window decorations.
- Recognizable application composites use locally installed [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme) SVG artwork. Papirus is GPL-3.0; see `licenses/Papirus.txt`. The builder adds velvet framing and selected palette changes. Missing sources inherit the installed icon theme.
- The optional white ChatGPT knot comes from the pinned official OpenAI brand bundle described in `assets/brand-sources.json`. It is fetched for local composition, not vendored in this source repository. Its geometry is preserved. OpenAI/ChatGPT names and marks belong to their respective owner; the project is unaffiliated.
- The Owl Cave-style Start symbol is a vector interpretation of the user-provided reference. Other motif SVGs and cursor sources were drawn for this skin. The identity references Twin Peaks; no official endorsement is implied.
- The painterly fox/curtain logo in `assets/identity/fox-lodge.png` is original AI-generated artwork commissioned for **Firefox Walk With Me** using the built-in imagegen tool. It combines an organic fox, velvet curtains, Douglas firs and a chevron floor. Its original transparent alpha is preserved. [Generation prompt and integration](branding.md). The actual Firefox application icon retains its own identity. Firefox is a Mozilla trademark; this skin is unaffiliated with Mozilla.
- The red-room wallpaper is commissioned AI-generated artwork from this desktop project, not a television still.
- **Into the Lodge** is an original 6.4-second synthesized cue, rendered by `tools/synth_startup.py`. It uses a low pedal, sustained chord, harmonics and echoes, with no show recording, sample, or borrowed melody.
- The outline title uses installed URW Gothic, with a sans-serif fallback. No font file is packaged.
