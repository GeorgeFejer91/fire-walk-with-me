# Skill routes

- Required when installed: `ponytail` for code and reviews; otherwise apply the same smallest-complete-change discipline.
- Conditional: `multi-source-web-search` for visual-reference research and uncertain technical facts.
- Conditional: `imagegen` for new bitmap artwork, not native SVG/XPM/CSS assets.
- Conditional: `uncodixfy` for the static HTML project page. The skin itself is native GTK/XFCE.

No external skill is vendored or downloaded by the installer. User instructions take precedence.
