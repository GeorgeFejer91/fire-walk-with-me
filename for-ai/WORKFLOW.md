# Workflow

Inspect relevant code and source credits. Change the smallest owner. Keep backups outside the checkout. Validate changes and visually inspect affected native screens.
Update the narrowest contract or decision when behavior changes. Stage exact intended paths, review the index, commit, push main without force, and verify the remote SHA.
Only publish selected screenshots made with synthetic or generic content. Do not stage full user profiles, runtime logs, credentials, or local backups.
